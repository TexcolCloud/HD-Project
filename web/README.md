# 寓见 Vue 管理端

正式宿管 Web 应用，使用 Vue 3、TypeScript、Vue Router 和 Vite。业务数据全部来自 Java `/api/v1`，不内置模拟业务数据。暖白与暖黑主题沿用已批准的界面基线。

## 启动

在本目录使用 Node.js 24.12 或以上版本：

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:5173。Vite 将 `/api` 代理至 http://127.0.0.1:8080。后端需要先启动；本地种子账号与密码见上级 `contracts/API.md`。学生账号不能进入宿管页面。

如后端地址不同，启动前设置 `API_PROXY_TARGET`。浏览器请求保持同源路径，不将登录 Cookie 或 AI 密钥放入本地存储；本地存储只保留主题偏好。

## 检查与契约

```powershell
npm test
npm run build
npm run format:check
```

`npm run generate:api` 使用 `openapi-typescript` 从 `../contracts/openapi.json` 生成 `src/generated/api.ts`，构建时自动执行。实体和请求类型引用该文件，不手工维护另一套 DTO。依赖精确版本与 `package-lock.json` 一起锁定，TypeScript 采用与契约生成器兼容的 5.9.3。

API 传输层测试覆盖组合查询、Cookie 与 CSRF 写请求、幂等头，以及非 JSON 代理响应的可读错误。页面验证还需启动实际后端，完成登录、写入、图片与角色范围的浏览器联调。

查询使用 `useLatestQuery` 按独立列表／详情管理取消与销毁，旧响应不能覆盖当前选择。房间、楼栋编辑及房间详情位于 `components/housing`，分别拥有表单和请求生命周期。格式由锁定Prettier管理，执行 `npm run format`；生成模型不手工格式化。当前API1.3能力、33项测试及浏览器逐项记录见[服务闭环与联合验收](../docs/16-服务闭环与联合验收.md)，[15](../docs/15-结构治理与联合回归.md)保留前次结构治理历史。

## 已实现

- 宿管登录、会话恢复、路由守卫、退出与修改密码。
- 楼栋和房间档案维护，房间详情与关联入住、工单。
- 学生档案及入住、调宿、退宿与历史。
- 工单筛选、处理时间线、受保护图片、接单、驳回、开始、进度说明、完工和返修。
- 卫生四项评分、图片、更正历史、关联复查与作废留痕。
- 访客登记、离访、按需查看联系方式及更正。
- 同范围入住、报修、卫生、访客统计与工单下钻。
- 多宿管路线、正常交接与有条件的异常接续；本人设备会话、通行校准与未知样本展示。
- 服务消息收件箱、已读和业务跳转；卫生整改责任期限、学生反馈、关联复查验收、退回与取消。
- 首次／重置改密引导与业务路由限制；官方纯文本AI研判展示、本人建议决策及结果留档。

所有写请求携带 Cookie 和 CSRF，业务提交带幂等键；网络重试复用同一内容对应的键，成功后清除。后台授权与版本校验仍是最终依据。图片先进行本地格式检查、缩放和重新编码，再上传鉴权接口；失败保留文字和待传图片，上传未完成时禁止提交业务表单。

生产部署需将 `dist/` 作为静态目录，并把 `/api/v1` 反向代理到 Java 服务；路由回退到 `index.html`，使用 HTTPS 与后端生产 Cookie 配置。Vite 开发服务器不作为生产部署方式。

## 设计资产与官方依据

本地字体和庭院照片复用已批准资产，许可文件位于 `public/assets/`。庭院图仅为校园生活氛围示意；图片署名及许可入口保留在登录与工作台。

初始化依据 [Vue 官方快速开始](https://vuejs.org/guide/quick-start.html) 和 [Vite 官方发行说明](https://vite.dev/releases)，依赖版本于 2026 年 11 月 7 日从 npm 官方发布包确认并在本机安装构建。
