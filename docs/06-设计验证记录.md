# 学生公寓平台设计验证记录

验证日期：2026 年 11 月 7 日，Asia/Shanghai。本次验证对象为需求与方案文档，以及浏览器中的离线设计预览。下列初版记录对应墨绿试稿，中段保留R2日间/夜巡历史；当前R3暖白编辑式方案的验证位于文末。结果可支持界面评审和后续建项，不能替代正式服务与鸿蒙应用验收。

## 文档一致性

需求、架构和接口经过交叉审阅，统一了以下业务口径：

- 两种业务角色，宿管按楼栋范围管理；学生只读本人报修与本人入住期间的宿舍卫生记录。
- 七种工单状态；待确认可带原因返修，已完成、已取消、已驳回为终态。
- 四类故障为水电、门窗家具、网络、其他；卫生四项为地面、桌面、床铺、卫生间，各25分。
- 故障图片、处理凭证分组各最多6张；每次巡检最多6张，单张10MB。
- 调宿保留旧房间与联系快照；访客按入访记录所属楼栋管理；卫生按实际检查时刻匹配入住区间。
- 房间容量/入住历史、不设独立床位；五张题目核心表加公共与支撑关系共15张。
- 未来正式目录统一为 `backend/`、`web/`、`harmony/`、`deploy/`。

审阅补齐了联系人快照、处理中追加说明接口、卫生复查关联、访客趋势统计、资源详情和敏感联系方式查看审计。相关设计均保存在对应文档中。

## 颜色对比度

按W3C相对亮度公式计算设计令牌前景/背景，四舍五入至两位。普通文字最低目标4.5:1，标准依据为 [WCAG 2.2 文字对比度](https://www.w3.org/TR/WCAG22/#contrast-minimum)。此检查只覆盖列出的颜色组合，不等于整站无障碍认证。

| 前景 / 背景 | 对比度 |
| --- | --- |
| 白字 / 主色 | 6.38:1 |
| 正文 / 白色表面 | 12.09:1 |
| 次要文字 / 白色表面 | 4.98:1 |
| 次要文字 / 页面背景 | 4.58:1 |
| 品牌文字 / 品牌浅底 | 5.62:1 |
| 警示文字 / 警示浅底 | 4.93:1 |
| 处理中文字 / 蓝色浅底 | 5.79:1 |
| 异常文字 / 异常浅底 | 5.13:1 |

## 视觉修订的字体与主题

视觉修订采用瓷蓝日间与深靛夜巡，在原有业务预览中增加主题切换。切换只修改主题属性与色彩方案，不重建业务表单；已验证报修标题、描述在日夜往返切换后保留。JavaScript语法检查通过。

正文、600字重、展示标题与数字字体共4个WOFF2文件，合计1,596,752 bytes；当前演示中文均有正文覆盖。字体以本地文件加载，来源、OFL许可及SHA-256清单保存在[字体资产说明](../design/assets/fonts/README.md)与[字体清单](../design/assets/fonts/font-manifest.json)。

日间与夜巡的正文/表面、辅助文字/画布、主按钮以及警示、处理、错误、成功标签的14组颜色组合取自浏览器实际计算的CSS变量，按相对亮度公式检查，最低4.95:1；[双主题令牌](../design/tokens.json)已与实际CSS同步，[颜色审计数据](../output/playwright/visual-r2-colors.json)保留具体前景、背景和比值。

浏览器复测结果：

- 两套主题 × 14个Web/鸿蒙页面场景 × 1440、768、375三档宽度，共84组，无整页横向溢出。
- 四个字体声明全部显示为loaded；正文、展示标题、房号分别命中Dorm Plex、Dorm Sign和Dorm Chivo。
- 夜间填写报修后切回日间，标题、描述、联系电话、联系时段、紧急程度与较急原因保留；AI生成时手工标题保持不变，采纳后仍需主动提交。
- 新建示例工单可在夜间Web详情中接单、开始处理；Esc可关闭详情，未因样式更新改变业务状态规则。
- 减少动态效果开启时仍可切换主题和访问所有场景；最终控制台无错误或警告。

## R3：按个人审美指南重做三端

本轮以[跨项目审美指南](../FRONTEND_AESTHETICS.md)为方向，将当前项目改为「暖白服务台／暖黑服务台」。通用指南保持原样；当前方案的具体色彩、字体与布局归入[项目设计规范](04-界面与设计规范.md)及[tokens.json](../design/tokens.json)。上面的墨绿、瓷蓝记录仅供历史比较。

### 视觉与资产

- Web使用炭黑导航、暖白纸面和扁平指标条，待办工单表优先于房间概览；学生端使用紧凑房间信息、庭院照片与明确报修入口；宿管端保留紧凑值班信息和访客、卫生快捷入口。
- 当前加载的四个WOFF2共1,692,972字节；正文Dorm Plex 400／600、标题Dorm Serif 600和数字Dorm Chivo均在浏览器显示为loaded。标题实际命中本地衬线族，正文和数据分别使用各自字体。
- 庭院照片实际加载为1200×801。页面图注明确为校园氛围示意，并提供摄影者、CC BY-SA 3.0及本地来源入口；完整署名、来源、许可和处理记录见[图片资产说明](../design/assets/images/SOURCES.md)。
- 配色规范页的展示色值、机器令牌与浏览器实际CSS变量已同步。日／夜14组正文、辅助文字、主按钮和状态标签组合最低5.21:1；学生报修入口分别5.64:1和6.98:1。详见[颜色审计](../output/playwright/editorial-r3-colors.json)。这些检查覆盖所列组合，不代表整站无障碍认证。

### 浏览器验证

- 两种主题×14个Web／鸿蒙场景×1440、768、375三档宽度，共84组，无整页横向溢出。表格、场景导航及手机内容区可按各自容器滚动。
- 减少动态效果开启时完成场景切换、主题切换和截图；配色规范页标题与当前主题一致。
- 报修标题、描述、联系电话、联系时段、紧急程度、较急原因在主题往返后保留；已添加的一张本地测试图片预览也保留。
- AI生成建议没有覆盖手工标题；点击「采纳建议」后才写入表单，并仍需点击提交。AI继续为本地规则演示，未连接模型。
- 提交后的示例工单可在Web中查看、接单、开始处理，最终显示「处理中」。Esc可关闭详情。
- 卫生评分将地面由23改为0后，合计为69、等级为合格；保存反馈与结果一致。
- JavaScript语法检查通过。最终浏览器控制台无错误和警告。独立静态视觉复核未发现阻断交付的高信心问题。
